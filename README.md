# HelpDesk Acadêmico — GitHub Pages

Versão visual profissional e estática do sistema para publicação no GitHub Pages.

## Publicação
1. Coloque `index.html` na raiz do repositório.
2. Coloque a pasta `assets` na raiz.
3. GitHub > Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: `main` e folder: `/(root)`.
6. Save.

Esta versão roda 100% no navegador. Os chamados são armazenados em `localStorage`; o login é demonstrativo, pois GitHub Pages não executa Flask/Python ou banco SQLite.
